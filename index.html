Algorithm guide

Ten common algorithms, grouped by what they do. The learning type shows whether the algorithm uses labeled examples.

Predict and classify

  • Decision TreeSupervised, tabular data

    Asks a series of yes or no questions until it reaches an answer. Example: approving or denying a loan.

  • Random ForestSupervised, tabular data

    Builds many decision trees and lets them vote. Example: predicting which customers will cancel.

  • Support Vector MachineSupervised, tabular data and NLP

    Finds the boundary that best separates two groups. Example: sorting email into spam and not spam.

  • CNNSupervised, computer vision

    Scans images in small pieces to find edges and shapes. Example: recognizing faces in photos.

  • BERTSupervised (fine-tuned), NLP

    Reads words in both directions to understand each word in context. Example: rating a review as positive or negative.

Find patterns

  • K-Means ClusteringUnsupervised, tabular data

    Places items into a set number of groups by similarity. Example: grouping shoppers by buying habits.

  • Principal Component AnalysisUnsupervised, tabular data and computer vision

    Reduces many columns into a few main patterns. Example: simplifying a large survey.

Generate

  • GPTSelf-supervised, NLP and generative AI

    Predicts the next word using patterns from large amounts of text. Example: writing summaries.

  • GANUnsupervised, generative AI and computer vision

    A generator and a discriminator compete until the fake images look real. Example: creating realistic faces of people who do not exist.

  • Diffusion ModelSelf-supervised, generative AI and computer vision

    Removes noise step by step until a clear image matches a prompt. Example: Stable Diffusion images from text.

Artifact 2: Neural Network Components

How data flows through a network

A neural network receives data at the input layer, transforms it in one or more hidden layers, and produces a prediction at the output layer.

Figure 1. A simple network with three input neurons, four hidden neurons, and one output neuron.

The six components

Layers

A group of neurons that work together on the same step. The input layer receives data, hidden layers process it, and the output layer gives the final answer.

Neurons

A small calculation unit. It combines its inputs using weights, applies an activation function, and passes one number forward.

Weights

Numbers that control how strongly each input affects a neuron. Training adjusts them so predictions improve.

Activation functions

Rules that decide how much a neuron passes on. They add non-linearity, which lets the network learn complex patterns. ReLU is a common example.

Loss functions

Measures of how wrong the predictions are. A high loss means the network needs to improve. Mean squared error and cross-entropy are common examples.

Optimization algorithms

Methods that use the loss to change the weights. Gradient descent moves weights to lower the loss, and Adam is a popular optimizer.

Training in short

  • The network makes a prediction from the input.
  • The loss function measures how far the prediction is from the correct answer.
  • The optimizer adjusts the weights to reduce the loss.
  • This cycle repeats until the predictions are accurate enough.

Summary

Visualizing a neural network makes it easier to explain how it learns. Seeing the layers, weights, and loss in one picture helps show why small changes in data, noise, or network size can affect results. Working in the Neural Network Playground showed me this in practice.
